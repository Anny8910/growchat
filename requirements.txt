# Direct dependencies — pinned.
# Generated against Python 3.12. Every version below is the current PyPI release
# at the time of writing. Bump deliberately, never as a side effect of a fix.
#
# WHY PIN EXACTLY (not ~=): the vector store is persisted to disk and reloaded by
# a process that may have been built at a different time (Render runs build and
# start as separate phases). A silent numpy/chromadb bump between build and run is
# how you get a 384-dim mismatch against a store written by a different build.
# See docs/implementation.md Phase 3.

torch==2.14.0

# Pinned transitively on purpose: numpy and onnxruntime sit under both the
